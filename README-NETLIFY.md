# موقع مركز الإتقان على Netlify (بلوحة إدارة وتسجيل دخول)

هذي النسخة تشتغل على Netlify بدون خادم تديره بنفسك. فيها:
- تسجيل دخول حقيقي للمدير بالإيميل وكلمة المرور، من أي جهاز.
- حفظ الدورات والتسجيلات والصور داخل Netlify (خدمة Blobs)، فما تضيع عند إعادة النشر.
- نفس لوحة الإدارة: الدورات، الأسعار، التسجيلات مع تصدير CSV، الصور، تغيير كلمة المرور.

## محتوى المجلد
| الملف | الدور |
|---|---|
| `netlify/functions/site.mjs` | نقطة الدخول: تربط الموقع بمخزن Netlify |
| `netlify/functions/core.mjs` | منطق الموقع: الدخول، الحفظ، التسجيلات، الصور |
| `netlify/functions/template.mjs` | قالب صفحة الموقع |
| `netlify/functions/defaults.mjs` | البيانات الأولية (دورات أمثلة) |
| `public/assets/` | الشعار، صورة الواجهة، وسكربت الموقع `app.js` |
| `netlify.toml`, `package.json` | إعدادات النشر |

## طريقة النشر (الموصى بها: GitHub)
1. أنشئ حسابًا مجانيًا على github.com، ثم مستودعًا جديدًا (Repository) وارفع إليه محتوى هذا المجلد.
2. أنشئ حسابًا على netlify.com، واختر **Add new site ← Import an existing project**، واربطه بالمستودع.
3. اترك الإعدادات كما هي (تُقرأ من `netlify.toml`) واضغط **Deploy**.
4. **قبل أن تفتح الموقع لأول مرة**: من **Site configuration ← Environment variables** أضف:
   - `ADMIN_EMAIL` = إيميلك
   - `ADMIN_PASSWORD` = كلمة مرور قوية
   ثم اضغط **Deploys ← Trigger deploy**. تُستعمل هذه القيم مرة واحدة فقط لإنشاء حساب المدير عند أول زيارة. هذان المتغيران إلزاميان: بدونهما لا تعمل لوحة الإدارة ولا نموذج التسجيل.
5. افتح الرابط الذي يعطيك إياه Netlify (يشبه `اسم-موقعك.netlify.app`). هذا الرابط يفتحه أي شخص.

### بديل: سطر الأوامر
بعد تثبيت Node.js:
```
npm install -g netlify-cli
npm install
netlify login
netlify deploy --prod
```

> الرفع بالسحب والإفلات (Netlify Drop) قد لا يشغّل الدوال أو لا يثبّت الحزمة المطلوبة، فاستعمل GitHub أو سطر الأوامر.

## الدخول إلى الإدارة
- اضغط **«دخول الإدارة»** أسفل الصفحة، أو أضف `/#admin` إلى الرابط.
- ادخل بالإيميل وكلمة المرور، وغيّرهما من تبويب **«الحساب»** عند الحاجة.

## دومين خاص
من **Domain management ← Add a domain** في Netlify، واتبع التعليمات. شهادة HTTPS تُفعَّل تلقائيًا.

## الأمان
- كلمة المرور مشفرة (scrypt)، وملف تعريف الارتباط موقّع ومحمي (`HttpOnly`, `SameSite`, `Secure`).
- حماية CSRF، وتحديد عدد محاولات الدخول (8 كل 10 دقائق) والتسجيل (6 في الساعة).
- رفع الصور يتحقق من محتوى الملف (PNG أو JPG أو WEBP، حتى 4 ميغابايت).

## ما يجب أن تعرفه
- كل تسجيل يُحفظ في ملف مستقل، وعرض اللوحة يقتصر على آخر 300 تسجيل، أما ملف CSV فيحوي الجميع.
- للخطة المجانية في Netlify حدود شهرية على الاستعمال. لموقع مركز تدريب عادي تكفي غالبًا، لكن راجع حدود خطتك الحالية في Netlify.
- هذا الكود اختُبر محليًا بمخزن مؤقت يحاكي Blobs، ولم يُختبر على Netlify نفسه. إن ظهر خطأ عند أول نشر، افتح **Logs ← Functions** وأرسل لي الرسالة.
